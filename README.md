# sakura-docs-practice

さくらインターネットのサービスを、初めて使う利用者の立場から確かめた記録です。
実際に操作し、公開文書を読み、どこで迷ったかを残しました。

テクニカルコミュニケーター／ライター職への応募準備として、筆者が個人的に作成しました。
さくらインターネット株式会社の公式文書ではありません。

---

## なぜ、これを作ったか

私は、利用者向けの文書を**作る側**にも、**読む側**にもいました。

大型放射光施設SPring-8では、分野の外から来る利用者向けガイドの制作と、
それに連動する公開Webサイトを担当しました。
その後、製造・電力・自治体・大学の現場で、
**止められない設備を前に、手順書のとおりに作業する側**を経験しました。
現在は、共用サーバーで約50件のメールアカウントを発行・管理し、
設定に困った利用者への一次対応もしています。

両側に立って、分かったことがあります。

> **動くものを作ることと、その前提を知らない人が使えるように伝えることは、別の難しさです。**

手順書から前提が一つ抜けるのは、書き手が雑だからとは限りません。
**書き手には当たり前すぎて無意識にまで沈み、その前提自体が見えなくなっていることがあります。**
それは、初めて使う人が実際にどこで止まるかを見て、
初めて見えてくるものです。
私自身、書く側で何度も同じ見落としをしてきました。

ですから、この記録は間違い探しではありません。
**外から来た一人の利用者が、どこで止まったか**を残したものです。
ここに並ぶ事象の多くには、
**外からは見えない設計上・運用上の理由があるはず**だと考えています。

そのため、断定せず、**質問**の形で残しました。

## 分かったこと

迷った場所は、いくつもありました。

翌日に探し直して分かったのは、その多くが**すでに説明されていた**ということです。

- ウェブメールの使い方も、Gmail 宛に届かないときの対処も、SPF・DKIM・DMARC の解説も、
  公式に用意されています
- 公式YouTubeチャンネルには初心者向けの解説が体系的に並び、
  「メール設定ガイド」という13本の再生リスト——つまり索引——まであります
- 一日かけて手探りしたことの、ほとんどが既に説明されていました

必要な情報は、すでに用意されていました。
一方で、初見の私は、必要な時点でそこへ辿り着けませんでした。

この記録は、その距離を測ったものです。

## この記録で伝えたかったこと

サービスを作る人と、初めて使う人の間には、知識や前提の差があります。
**分かっている人には、初めての人がどこで止まるかが見えにくいことがあります。**

今回、私は初めて使う側に立ち、止まった場所を一つずつ記録しました。
私は、そうして見つかった距離を、文書で埋めたいと考えています。

初めての人が最初の成功にたどり着くまでの道のりを、少しでも短くする。
この記録が、そのための手掛かりになれば幸いです。

---

## この文書の作法

- 感想ではなく、**再現できる観察**として書く
- **事実・分析・未確認・質問**を分ける
- 公式文書を「誤り」と断定しない。観測した事実と、確認したい質問に分ける
- 実施していないことを、実施したとは書かない
- 良かった点も同じ密度で書く

推測から書いて誤った箇所は、**訂正の経緯ごと残しています**（記録002・004・010）。
いずれも「片側の文書だけを読んで結論を出した」ことが原因でした。
検出して直せることも、記録の一部と考えています。

---

## これは何ではないか

- さくらインターネット株式会社の公式文書ではなく、同社の見解を代表するものでもありません
- 同社から依頼・許可を受けて作成したものではありません
- 公式文書の誤りを指摘する目的で作成したものではありません
- STEP 4 改訂案は、採用された改善案ではありません

## 実施していないこと

- メールソフトの「サーバー名」欄に独自ドメインを入れた場合の確認
  （独自ドメインでの送受信そのものは確認しました）
- Windows のメールソフトでの確認
- 技術に詳しくない読者による読解テスト
- 他の受信サービスでの確認（迷惑メール判定の検証は Gmail のみで行いました）

実機検証はお試し期間中の環境で行い、実施者は1名です。
ユーザビリティテストの手法に則ったものではありません。

各文書の［未確認］の表記は、その時点で確かめていない事柄を示します。
